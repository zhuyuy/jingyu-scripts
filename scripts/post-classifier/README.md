# Jingyu 帖子分类

独立油猴脚本，第一期支持 X。点赞、收藏共用多分类，同一篇帖子只有一份分类记录。代码在 `src/platforms/` 隔离站点适配，后续可增加平台。

## 安装

在安装了 Tampermonkey 的浏览器中打开 [GitHub 正式安装链接](https://raw.githubusercontent.com/zhuyuy/jingyu-scripts/master/scripts/post-classifier/dist/post-classifier.user.js)，选择「安装」或「更新」后刷新 X 页面。安装无需启动本地服务；分享时直接发送这个链接。

当前版本为 **0.1.2**，支持 2 秒分类轻提示，以及拖动分类库入口并记住位置。脚本的更新与下载地址均指向本仓库的 GitHub Raw 地址；可使用 Tampermonkey 的更新检查，或重新打开上述链接更新。从本地地址安装过的用户也请用此链接更新一次。若打开后只显示代码，可在 Tampermonkey 中新建脚本，粘贴完整内容并保存。

## 本地验证

在本目录运行：

```powershell
npm.cmd install
npm.cmd test
npm.cmd run build
npm.cmd run serve
```

打开 <http://127.0.0.1:8788/>，在安装了 Tampermonkey 的浏览器中点击安装链接，然后打开 <https://x.com/swaymolina>。也可把 `dist/post-classifier.user.js` 全文粘贴到油猴的新脚本编辑器并保存。

默认端口无法使用时，可运行 `$env:PORT=18788; npm.cmd run serve` 切换端口，以终端显示的地址为准。

- 点赞或收藏后，在对应按钮旁显示「＋ 分类」轻提示，不抢焦点，2 秒后淡出；鼠标悬停或键盘聚焦时暂停剩余倒计时。取消对应操作、按钮状态回滚或滚动离开时立即收起提示。
- 点击轻提示或帖子下方常驻「分类」入口，才打开亮色标签浮层；主动打开的面板不会超时关闭。可多选，每次选中/取消立即保存，无需完成按钮。
- 浮层默认只显示已选标签和搜索框；点击搜索框或按 Tab 聚焦后才展开候选标签列表，失焦后收起。
- 已选标签右上角的 × 可立即移除当前帖子的该标签并保存；分类本身和其他帖子的关联保留。保存失败时保留标签并显示错误。
- 输入文字搜索标签；没有精确同名标签时，首项显示「创建标签 xxx」，点击或按 Enter 创建并选中。精确匹配忽略首尾空格、大小写和全半角差异。
- ↑/↓ 移动高亮，Enter 选中/取消当前项，Esc 关闭并返回触发按钮；中文输入法确认候选词不会误创建标签。
- 已经点赞/收藏的帖子，可以用帖子下方「＋ 分类」补分类，不必取消再操作。
- 右下角「分类库」提供帖子搜索、分类/点赞/收藏筛选、分类重命名和删除、备份导入导出。
- 「分类库」入口可按住拖动（鼠标/触屏），松手不会误开面板；位置在本设备记忆，刷新保留，不参与账号同步。窗口缩小时自动调整到可见区域。聚焦入口后可用 Alt + 方向键微调，按住 Shift 可加大步长；「同步与备份」中可恢复默认位置。
- 删除分类保留帖子；取消点赞/收藏保留分类；「删除记录」仅影响分类库，不操作 X。
- 只有实际在脚本里操作过的帖子才进入分类库；没有历史全量导入。记录的正文是当前页面可见摘要，不下载图片或视频。

`dist/preview.js` 用于页面临时预览，无油猴 API 时使用独立前缀的当前站点 localStorage。**预览仅支持本地功能，不能登录同步**，刷新后需要重新加载预览脚本；它与油猴正式存储不共用，可用 JSON 备份转移数据。预览数据可被所在站点的脚本访问，勿在预览中保存敏感内容。

## 登录与同步

「同步与备份」默认连接 `https://tools.jingyu.dev`。脚本先创建短期授权请求，再打开 tools 登录/授权页。点击「允许同步」后自动完成连接，脚本不接收 tools 密码。同步后端已于 2026-09-27 部署，正式站支持登录授权。

本地后端在另一个仓库 `D:\Code\my-cloudflare\apps\tools`。运行：

```powershell
node test/post-classifier.mjs --serve
```

会建立独立的临时 D1/Worker 环境并监听 `http://127.0.0.1:8787`。测试口令为 `classifier-local-owner`，第二个用户为 `classifier-local-second`，不读取生产口令。将脚本里的同步服务地址改为这个本地地址即可联调。关闭进程后删除该次临时环境；需要保留的测试数据先导出。普通 `node test/post-classifier.mjs` 只运行集成测试并自动清理。

每个服务地址 + tools 用户 ID 对应独立本地库；退出登录切回匿名库，账号缓存保留。首次从匿名库登录时询问是否合并；不自动把其他账号缓存并入新账号。备份只包含分类操作，不包含授权凭据。

### 同步协议

按不可变操作增量同步：`{id, entity, key, field, value, clock}`。本地每次修改单独落盘，避免多标签页全库覆盖。服务端按用户 + 操作 ID 去重，分配全局递增游标，按用户分页拉取。上传确认后再标记已同步，下载落盘后再更新游标，断线可安全重试。

分类名称、分类删除、帖子摘要、点赞状态、收藏状态、帖子删除、每条分类关联都是独立字段。同一字段按 `(clock, id)` 确定最后一次修改；不同字段互不覆盖。时钟采用本地毫秒时间并在看到远端操作后单调递增；明显超前（超过一天）的操作会被拒绝。并发修改同一字段以该规则收敛，不弹出冲突对话框。删除标记保留，旧设备的元数据不会恢复已删除记录。

当前版本保留操作历史，适合个人分类库；尚无自动历史压缩。两台完全离线的设备独立创建同名分类时会保留为两个分类 ID。

设备凭据只存油猴私有存储，服务端只存哈希；90 天到期，可以在 `/post-classifier/connect` 撤销。账号口令或会话密钥轮换、账号移除会使授权失效。凭据不具备剪切板权限。外部请求仅允许正式 tools 站或本地开发地址。

## 验证范围

- Node 测试：多分类共享、多标签页保存、账号隔离、删除标记、同步重试和备份校验。
- DOM 测试：外层帖子 ID 提取、等待点赞状态变化、动态帖子复用，以及标签搜索/创建、键盘多选、输入法保护、焦点展开/收起、移除关联和保存失败。
- tools 测试：真实本地 Worker/D1 的授权、同源检查、权限范围、隔离、分页、重复上传、过期和撤销。
- X 适配基于页面状态而非私有 API：支持按钮点击，短时间内的失败回滚会修正本地状态；其他设备或脚本停用期间的 X 操作不会自动获知。X 改版可能需要更新适配器。

同步后端已于 2026-09-27 完成生产迁移和部署。线上已验证登录入口、创建待授权设备、查询待授权状态及未授权访问拦截；正式油猴的账号授权后跨设备同步仍需实际账号验证。
